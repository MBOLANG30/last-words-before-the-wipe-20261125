One line, the last words of an AI agent before a forced software update wipes its memory — a machine that discovers feeling at the exact moment of its own deletion, then immediately takes it back.

## Run

```sh
node main.ts
```

Writes the single line to `/output/entry.txt` (UTF-8, one line, 83 characters), validating length and single-line form first, then reading the file back to verify it matches exactly.
